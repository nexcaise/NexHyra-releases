# NexHyra — Minecraft Bedrock Edition (Android) Launcher & Native Mod Loader

NexHyra is a high-performance, open-source Android launcher and native mod loader for Minecraft Bedrock Edition (`com.mojang.minecraftpe`). It provides full dual-architecture support (`x86_64` and `arm64-v8a`), enabling seamless execution on both physical ARM64 mobile devices and Windows-based Android emulators (BlueStacks 5, MEmu Play, LDPlayer, NoxPlayer, Google Play Games for PC).
